LENDIHUB — PRODUCT PAGE REDESIGN + ICONS
29 Oct 2026

READ THIS FIRST
  Last time you uploaded the HTML but not the stylesheets. That is why
  the comparison block rendered as plain stacked text — .product-grid
  and .product-card had no rules on the server.

  This release will look wrong in exactly the same way unless you
  upload styles.css AND vertical.css along with the HTML.

  Every page now asks for styles.css?v=3 and vertical.css?v=3, so
  browsers that cached the old files will pull fresh ones. Keep the
  ?v=3 on the links.

WHAT CHANGED VISUALLY

  Comparison block ("Three ways to do it")
    Was: three bare text blocks with no styling at all.
    Now: three cards, each with its own icon, a divided row for
    "Best when / You pay it back / It ends", a "Read more" link on
    the two you are not on, and the current product marked with a
    green border, mint background and a "You are here" pill.
    Stacks to one column below 860px.

  Icons (inline SVG, no image files, no external requests)
    Working Capital  banknote
    Term Loan        calendar with a check
    Line of Credit   cycle arrow around a dollar
    Plus a tick and a cross on the fit / not-fit cards, and a
    question mark on "Ask this before you sign".
    They inherit colour from CSS, so they stay on-brand if you
    change the palette later.

  Fit / not-fit cards
    Coloured left edge (green / amber), icon in a tinted square,
    uppercase heading. The two columns now read as opposites at a
    glance instead of two identical cream boxes.

  Line of Credit steps
    "One / Two / Three" labels are now navy numbered circles.

  Term Loans "what a lender looks at"
    Converted to the same fit / not-fit treatment, so the credit
    qualifier reads as a real gate rather than a list.

  Section labels
    Short green rule under each one. Small thing, but it gives every
    section a visible start.

  Comparison section now sits on white so it separates from the
  cream page background.

  Also fixed: the first H2 on each product page was repeating the H1
  almost word for word. Now distinct, and baked into the generator so
  it does not come back.

UNCHANGED
  All copy, all CTAs to form.html, no amounts or rates anywhere,
  reading level 4.0-4.4.

VERIFIED
  All 12 pages: div / section / footer / nav / svg / ul / a tags
  balanced, every internal link resolves, cache keys bumped.
  Rendered at 390px and 1280px, no horizontal scroll, no JS errors.
